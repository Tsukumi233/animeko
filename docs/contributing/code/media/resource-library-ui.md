# 资源页面

主导航的资源页由 `ResourceLibraryScreen` 提供，包含我的资源、来源、下载三个页签。下载页使用 `DownloadManagementScreen`，来源设置使用现有数据源设置入口。

番剧选集区域的关联入口通过 `NavRoutes.ResourceLibrary` 携带当前条目。播放器选源面板的“选择其他视频”还携带当前播放剧集的身份，直接打开来源页。确认窗口预载该条目的完整剧集；当前集选择单文件时预填对应关系，显示“确认并播放”。成功保存后以资源 ID 导航到该集，返回和取消保留已有播放页。剧集身份来自当前页面状态，不使用可编辑的搜索请求提示字段。

播放窗口接收拖放列表中的首个视频文件，将其绝对路径和拖放时的播放会话剧集 ID 交给同一入口。本地访问模块将路径规范化为稳定文件 URI，索引后打开关联确认；每个页面实例只消费一次初始文件列表。拖放本身不选择临时候选或写入观看进度。

`ResourceLibraryViewModel` 协调本地文件选择、来源配置、资源索引与关联确认。Android 文件选择保留 document/tree 的只读授权；Desktop 文件选择保存文件 URI。WebDAV 和 SMB 的凭证单独保存，PikPak 使用已有账号配置。

来源页过滤内部 `LocalCache` 实例，托管下载由下载页管理。WebDAV/SMB 提供连接编辑和移除入口；SMB 可配置端口与共享内相对子目录。编辑窗口不装载已有密码，同账号密码留空时保留凭据，账号变化时不继承旧密码。参数保存失败时恢复原凭据，配置变化会关闭已有浏览快照。移除连接保留资源关联、原文件与托管下载；该连接的资源在重新接入前不可访问。

`ResourceBrowserController` 负责来源浏览、分页与搜索。搜索范围来自 `MediaSourceBrowser.searchScope`；只支持搜索的来源显示关键字提示。BT 发布通过 `TorrentResourceBrowser` 展开完整文件路径，非视频文件不能关联。切换来源、目录或搜索请求时取消旧任务，并用请求标识阻止迟到结果覆盖页面。

播放器简洁选源列表包含网站、本地文件、文件服务和网盘。网站按线路展示，个人来源按文件版本展示。已确认的当前剧集 ID 提供与精确集号相同的匹配精度，其他剧集资源仍被排除；关联不覆盖语言、质量和来源偏好。

文件选择跨页面保留。确认窗口通过已有条目搜索获取候选，再加载包含 SP 的完整剧集信息，使用 `ResourceAssociationPreviewBuilder` 提议对应关系。用户可以逐个修改、按显示顺序分配或跳过文件。只有所有参与关联的文件都指定剧集后，才调用 `AssociateResourcesUseCase` 提交。关闭窗口会取消条目加载，重新打开的窗口具有独立请求标识。

打开确认窗口时按资源身份和完整文件路径恢复已保存的绑定与跳过决定。全部文件都跳过时也可以提交。重新确认某个文件只清除该文件的跳过决定，同一个 BT 发布内其他路径的决定保持独立。

`ResourceBrowserControllerTest` 覆盖分页、取消、来源隔离和错误恢复；`ResourceBrowserScreenTest` 使用合成输入验证搜索与文件选择，并比较窄屏和宽屏截图。截图宿主提供 Material Surface，使颜色和内容绘制与页面宿主一致。这些测试不验证系统选择器或原生播放器。

来源页列出已保存的扫描目录，支持扫描状态、错误、取消、重试和移除。移除仅停止该目录的扫描追踪，保留资源索引、可用性、绑定及原文件；在途结果无法提交到已移除的根。开始扫描前必须保存根引用。

目录的匹配规则入口使用 `ResourceScanRuleController`，复用条目搜索并加载包含 SP 的完整剧集。确认页展示精确目录范围、接受的标题、连续集号或季内集号与剧集的对应表；可排除有冲突或不参与匹配的剧集。空标题列表必须显式选择接受所有标题。用户确认作用域与映射后才能保存；修改选择会清除本次确认勾选。保存规则不立即修改资源关联，普通关联确认也不生成规则。已保存的绑定与跳过决定由扫描用例保护。

浏览来源时，`MediaSourceBrowser.rootEntry()` 可返回该来源自身生成的配置根容器，控制器使用真实根引用显示路径和目录操作；`browse(null)` 保持其既有语义。根容器返回来源列表时关闭浏览，子目录返回实际父级。网络搜索型来源不请求根节点。

没有原生搜索能力的来源使用“搜索已索引内容”：仓储只检索该来源已保存的文件名和路径，界面明确排除未扫描内容。搜索结果复用存储引用；BT 文件路径来自已有绑定、建议或跳过记录，保持完整路径。移除单文件索引时一并清理引用该视频的扫描根，不影响非递归目录根。

规则窗口显示可读的来源和目录名称，引用身份用于后台验证。作用域确认放在集数对应预览之前，长篇剧集目录可以独立向下查看。

我的资源和待关联列表在每个文件版本旁显示来源类型、可读来源名称及剧集信息。同名文件可据此区分；BT 文件保留完整相对路径，已移除来源使用不可用提示，不输出凭证或不透明引用。
